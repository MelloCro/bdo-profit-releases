# BDO Profit Tool — releases

Download the latest build from the [Releases](../../releases) page.

| File | Use |
|---|---|
| `BDO Profit Tool Setup <version>.exe` | Installer, with Start-menu and desktop shortcuts |
| `BDO-Profit-Tool-portable-<version>.exe` | Single file, no install |

The app updates itself: it checks this repo on launch, and there is a
**Check for updates** button on the Mastery tab.

Builds are unsigned, so Windows SmartScreen warns on first run — *More info →
Run anyway*.

---

This repository holds **only the built binaries**. It exists separately from the
(private) source so the auto-updater can read releases without shipping a GitHub
token inside the application.
